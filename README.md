# Codex Context Warning

Хук для локального Codex, который при заполнении контекстного окна от 50% поручает агенту предупредить пользователя и сохранить точку продолжения

## Что происходит

После ответа хук проверяет метрику последнего запроса. При достижении порога агент получает поручение сохранить цель, принятые решения, открытые вопросы, пути к артефактам, проверки и следующий шаг в `progress/context/<hash>-handoff.md`

Предупреждение выдаётся один раз на сессию. Новый чат автоматически не создаётся, текущая безопасная работа продолжается. При сжатии контекста предусмотрено дополнительное поручение сохранить заметку после сжатия

## Установка в свой проект

Требуется Python 3 и локальная версия Codex с поддержкой command hooks. Пример команды ниже рассчитан на macOS/Linux; Windows этой поставкой не проверен

1. Скачайте репозиторий через GitHub: **Code → Download ZIP**
2. Скопируйте `tools/context-warning.py` в папку `tools` своего рабочего проекта. Важна эта структура: скрипт сохраняет состояние в `progress/context` на уровень выше папки `tools`
3. Создайте в своём проекте `.codex/hooks.json` из `hooks.example.json`. В трёх командах замените `/ABSOLUTE/PATH/TO/YOUR/PROJECT` на полный путь к проекту. Для пути с пробелами оставьте двойные кавычки. Если Python вызывается другой командой, замените `python3`
4. Если `.codex/hooks.json` уже существует, добавьте группы событий к существующим настройкам. Не заменяйте файл целиком и не подключайте этот хук дважды
5. Откройте Codex CLI в этом проекте, выполните `/hooks`, проверьте и доверьте новые определения. Откройте новую сессию, чтобы конфигурация загрузилась
6. Добавьте `progress/context/` в `.gitignore` своего проекта: заметки агента могут содержать внутренние решения и пути к файлам

Официальная документация OpenAI: [Hooks](https://learn.chatgpt.com/docs/hooks)

## Проверка

Для проверки скрипта скопируйте также `tools/test_context_warning.py` и выполните из корня проекта:

```sh
python3 -B tools/test_context_warning.py
```

Проверяются порог 49/50%, отсутствие повторов и циклов, отсутствие метрик, использование последнего запроса вместо накопительного расхода, сжатие, отдельные сессии и отсутствие текста переписки в выходе и числовом состоянии хука

Эти тесты проверяют обработчик. Фактический запуск событий в вашей версии Codex проверяется отдельно через `/hooks` и реальный чат. После срабатывания убедитесь, что агент действительно создал заметку, и передайте её новому чату вместе с задачей

## Границы

- Заполнение оценивается как `last_token_usage.total_tokens / model_context_window`. Это приблизительная метрика последнего запроса, а не расход квоты подписки
- Если метрика недоступна, хук не выдумывает процент. Резервное поручение приходит после сжатия
- Хук читает до 2 МБ хвоста локального transcript для поиска метаданных. Текст сообщений не выводится и не копируется в состояние; сетевых запросов, API-ключей и сторонних библиотек нет
- Смысловую заметку пишет агент, а не скрипт. Корректность её содержания нужно проверить
- Формат transcript может меняться между версиями Codex. Совместимость со всеми версиями, Claude Code и облачными сессиями не заявлена
- Порог 50% выбран автором, его оптимальность не доказана
- Экономия токенов, денег и лимита подписки не измерена. Хук добавляет продолжение ответа и запись заметки, что тоже расходует токены

## Отключение

Отключите именно этот обработчик через `/hooks` или удалите только его группы из `.codex/hooks.json`, сохранив остальные хуки. Созданные заметки можно оставить
